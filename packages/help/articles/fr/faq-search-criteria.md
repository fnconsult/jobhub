title: À quoi servent les critères de recherche, et comment les modifier ?
synonyms: [critères, critères de recherche, poste recherché, métier, lieux, ville, rémunération, contrat, cdi, secteurs, domaines, modifier mes critères, préférences de recherche]
---
Chaque profil a ses critères de recherche : « Poste recherché », « Lieux », « Salaire annuel brut minimum (en euros) », « Type de contrat », « Télétravail », « Secteurs », « Sous-secteurs » et « Domaines ». Jobbbox s'en sert pour le Match Score, le mot-clé cible de l'ATS Score et la recherche d'offres.

Ils se modifient sur place, dans la fiche du profil : changez une valeur, elle est enregistrée, et « Critères enregistrés » le confirme. Vous pouvez indiquer jusqu'à 5 lieux : une offre proche de l'un d'eux vous correspond. Pour le contrat, le télétravail et les secteurs, cochez tout ce qui vous convient ; rien de coché veut dire pas de préférence.

Modifier les critères ne renomme pas le profil. Les scores d'une recherche d'offres sont recalculés avec les critères actuels du profil. Un profil archivé doit être restauré avant de changer ses critères.

Pour vous aider à les choisir, cliquez sur la suggestion « Affiner mes critères » dans la conversation du profil.
