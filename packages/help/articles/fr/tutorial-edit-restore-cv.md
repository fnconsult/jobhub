title: Modifier et restaurer son CV de référence
synonyms: [modifier mon cv, éditer, corriger, cv de référence, version, versions, historique, restaurer, revenir en arrière, ancienne version, annuler, master cv]
---
Chaque enregistrement de votre CV de référence crée une nouvelle version. Les précédentes restent consultables et peuvent être restaurées.

1. Ouvrez le profil, puis sa rubrique « CV de référence ».
2. Modifiez sur place le « Titre du CV », le « Profil (résumé) » ou les « Compétences, une par ligne », puis cliquez sur « Enregistrer la version … ». « Annuler » abandonne vos modifications.
3. Pour vos coordonnées, vos postes, vos formations et vos langues, cliquez sur « Modifier mon CV de référence » : l'éditeur complet s'ouvre. Ajoutez, modifiez, déplacez ou retirez les éléments, puis cliquez sur « Enregistrer une nouvelle version ».
4. Pour revenir en arrière, cliquez sur « Historique des versions », dans la rubrique « CV de référence ». La version actuelle est marquée « Version actuelle ».
5. Cliquez sur « Voir la version … » pour la relire, puis sur « Restaurer la version … ».
6. La version restaurée devient la version actuelle, marquée « Restaurée depuis la version … ». L'historique est conservé : rien n'est perdu.

Un CV adapté déjà enregistré sur une candidature ne change pas quand vous modifiez votre CV de référence ; une proposition en cours, elle, est à redemander.
