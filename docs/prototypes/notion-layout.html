    Notes du prototype

    Les choix à valider avant de reconstruire les vraies pages. Toutes les données sont des exemples.

    Mise en page

    • Barre latérale de 17rem, dans l'ordre : Profils (avec sélecteur), Candidatures, Recherches d'offres, Job Digests, Mon compte, Abonnement. Taille du texte en bas, toujours visible.
    • « Masquer le menu » la retire entièrement : jamais de rail d'icônes sans texte (ADR-0009). Le bouton « Menu » la rouvre.
    • Sous 64rem, la barre devient un tiroir par-dessus la page. Échap, le fond grisé ou un lien la referme.
    • Une colonne de lecture de 44rem, comme aujourd'hui. Le panneau du coach (24rem) s'ancre à droite à partir de 80rem, sinon il s'ouvre par-dessus la page.

    Échelle typographique

    Celle des jetons, sans taille en dessous de 1rem : 16px (texte, libellés, badges), 18px (chapeau, titres de ligne), 20px (titre de section secondaire), 24px (h2), 32px (h1). Gras 600 pour les libellés et l'élément actif, 700 pour le titre de page. Police système.

    Espacement

    • Grille de 4px des jetons : 32px entre sections, 16px dans une section, 8px entre contrôles.
    • Toute cible cliquable fait au moins 44px de haut (2,75rem).
    • Marges de page : 48px sur grand écran, 16px sur téléphone.

    Modification sur place

    • Un champ modifiable est souligné en tirets, d'une couleur à 3:1 : visible sans survol, donc aussi au doigt.
    • Statut, profil, critères, fréquence : enregistrés dès le changement, avec « … enregistré » à côté.
    • CV de référence : les modifications s'accumulent, puis « Enregistrer la version 8 » crée une version (ADR-0012). Accepter une ATS Fix enregistre aussi une version.

    Composants nécessaires

    • Radix (ADR-0018) : menu déroulant (sélecteur de profil), onglets (documents adaptés), dialogue (tiroir de navigation et panneau du coach sous 80rem).
    • HTML et CSS simples : liste de propriétés, champ modifiable sur place, badge de statut, score, carte d'action, ligne de liste, barre d'enregistrement, contrôle de taille du texte, fil d'Ariane, message bref.
    • Deux jetons à ajouter : le fond grisé derrière un tiroir et l'ombre des éléments superposés.
