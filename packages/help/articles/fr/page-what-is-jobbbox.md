Jobbbox vous accompagne dans votre recherche d'emploi, avec un coach IA. Il construit avec vous votre CV de référence et vos critères de recherche, cherche les offres d'emploi qui vous correspondent, puis prépare vos candidatures : un CV adapté à chaque offre, une lettre de motivation. Vous suivez ensuite vos candidatures, vos entretiens et vos relances au même endroit.

Jobbbox s'adresse à toute personne qui cherche un emploi, que ce soit pour la première fois ou après des années dans le même poste. Il est fait pour être lu sans effort : pas de jargon, un article d'aide pour chaque mot à connaître, et un texte que vous pouvez agrandir.

Votre coach est une IA, et il le dit. Si vous le souhaitez, des coachs humains peuvent aussi vous accompagner, en séances payées à part. L'extension Chrome Jobbbox, elle, enregistre une offre depuis la page où vous la lisez.

Cette page, « Se connecter à Jobbbox », sert aussi à créer votre compte : pas de mot de passe, saisissez « Votre adresse e-mail » puis cliquez sur « Recevoir mon lien de connexion ». Si vous n'avez pas encore de compte, il est créé, avec l'offre Gratuite : rien à payer pour commencer.

L'e-mail reçu contient un lien et un code à 6 chiffres. Vous le lisez sur un autre appareil, votre téléphone par exemple ? Restez sur cette page : saisissez le code dans « Saisir le code reçu par e-mail », puis cliquez sur « Me connecter avec ce code ». Le lien et le code sont valables 15 minutes et une seule fois : utiliser l'un rend l'autre inutilisable. Au bout de 5 codes faux, le code ne fonctionne plus : cliquez sur « Recevoir un nouvel e-mail ».

Selon les moyens proposés sur la page, « Continuer avec … » suivi de Google, Apple ou Microsoft vous connecte avec un compte que vous avez déjà, sans attendre d'e-mail. Avec Apple, vous pouvez choisir de masquer votre adresse e-mail : Apple transmet alors une adresse relais, et votre compte Jobbbox est un nouveau compte, distinct de celui de votre adresse habituelle. Si un compte Jobbbox utilise déjà l'adresse de ce compte, la page peut vous demander de vous connecter d'abord en recevant un lien par e-mail, puis d'associer ce moyen de connexion depuis « Mon compte ».

Dans l'app Jobbbox, l'écran « Se connecter à Jobbbox » propose les mêmes moyens, au-dessus du lien par e-mail. « Continuer avec … » ouvre la page du fournisseur dans le navigateur du téléphone, par-dessus l'app ; sur iPhone, le système vous demande d'abord d'autoriser Jobbbox à l'ouvrir. Une fois connecté chez le fournisseur, vous revenez dans l'app, connecté. Vous fermez cette page ou touchez « Annuler » ? Rien ne change : l'écran de connexion vous attend, choisissez un autre moyen. Une connexion par Google, Apple ou Microsoft ne demande pas de deuxième étape, même si votre compte a la vérification en deux étapes.
