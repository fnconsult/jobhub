title: Valider une Coach Page
synonyms: [profil public coach, modération présentation, photo coach]
---
1. Avec le rôle Responsable coaching ou Super-admin, ouvrez « Coachs humains », puis « Profils de coachs à valider ».
2. Relisez la présentation, les spécialités, les langues et le portrait proposé. Une version en attente n’est pas servie aux Candidates ; la version approuvée précédente reste affichée.
3. Choisissez « Approuver le profil » pour publier cette proposition, ou renseignez « Motif du refus » puis « Refuser le profil ». Le motif est obligatoire et repris dans l’e-mail au coach.
4. Si le coach a soumis une nouvelle proposition entre-temps, rechargez la file : l’ancienne décision ne peut pas remplacer la version la plus récente. La décision validée est inscrite dans Actions des administrateurs.
