Une notification de l'app (en anglais, push notification) est un court message que l'app Jobbbox affiche sur l'écran verrouillé de votre téléphone ou de votre tablette quand un événement vous concerne : de nouveaux résultats pour une recherche d'offres, un Job Digest, un rendez-vous le lendemain, un avis de votre coach, une relance à faire.

Son texte ne nomme jamais une entreprise, un poste ni une personne, puisque l'écran verrouillé se voit : « Nouveaux résultats pour une recherche ». La toucher ouvre l'app sur ce qu'elle annonce, où le détail s'affiche.

L'app ne vous notifie qu'après que vous l'y avez autorisée. Dans Mon compte, rubrique « Rappels », « Notifications de l'app » a un interrupteur par événement ; vous pouvez aussi couper toutes les notifications dans les réglages de votre appareil. Les e-mails de rappel restent envoyés comme vous les avez réglés.
