La section Rétractations distingue les rétractations légales et le suivi des annulations contractuelles de séances. Le rôle de support disposant de l’écriture peut relancer un remboursement en échec ; les autres accès autorisés restent en lecture seule. Le motif du coach est une donnée privée, jamais une note publique.

Les remboursements déjà dus restent dans la liste financière après l’effacement du compte et du suivi personnel. Aucun nom, adresse ou motif effacé n’est reconstitué. Une demande privilégiée de reprise est auditée avant la tentative financière ; son résultat est conservé dans les faits de remboursement.

Un état incertain demande une réconciliation dans le compte Stripe d’origine. Ne créez pas de nouveau remboursement en devinant le résultat d’une ancienne écriture. Les conditions d’activation sont validées séparément par les responsables humains ; cette page n’approuve aucun texte juridique.
