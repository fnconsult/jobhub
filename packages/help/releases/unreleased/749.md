## fr
- L'e-mail de connexion contient aussi un code à 6 chiffres : vous le lisez sur votre ordinateur et vous vous connectez dans l'app, ou l'inverse, en saisissant le code dans « Saisir le code reçu par e-mail ». Comme le lien, il est valable 15 minutes et une seule fois.

## en
- The sign-in email also holds a 6-digit code: read it on your computer and sign in to the app, or the other way round, by typing the code in « Enter the code from the email ». Like the link, it is valid for 15 minutes, once.
