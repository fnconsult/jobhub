title: Code de secours

Un code de secours remplace le code de votre application d'authentification quand vous ne l'avez pas sous la main, par exemple si vous avez perdu votre téléphone. Jobbbox vous en donne 10 quand vous activez la vérification en deux étapes, affichés une seule fois : copiez-les ou téléchargez-les, et gardez-les en lieu sûr.

Chaque code ne sert qu'une fois. La rubrique « Sécurité » de Mon compte indique combien il vous en reste ; « Régénérer les codes de secours » vous en donne 10 nouveaux, et les anciens cessent de fonctionner. Jobbbox ne garde pas vos codes en clair et ne peut pas vous les montrer à nouveau.
