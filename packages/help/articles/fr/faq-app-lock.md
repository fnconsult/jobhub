Dans l'app Jobbbox, ouvrez le menu, puis « Réglages de l'app » sous « Mon compte », et activez « Verrouiller l'app ». L'app vous demande aussitôt Face ID, votre empreinte ou le code de l'appareil, pour vérifier que vous pourrez la déverrouiller.

Une fois le verrouillage activé, l'app se verrouille quand elle reste 5 minutes ou plus en arrière-plan, et à chaque démarrage. Pour revenir, passez Face ID ou votre empreinte ; après plusieurs échecs, le code de l'appareil prend le relais. Si vous annulez, touchez « Déverrouiller » pour réessayer. Tant que le verrouillage est activé, le contenu de l'app est masqué dans le sélecteur d'apps ; sur Android, les captures d'écran de l'app sont aussi bloquées.

Ce réglage ne vaut que pour cet appareil : il ne se retrouve ni sur le site ni sur un autre téléphone, et rien n'est envoyé à Jobbbox. Ce n'est pas une vérification en deux étapes : votre connexion ne change pas. Votre visage et votre empreinte sont vérifiés par le système de l'appareil (iOS ou Android) ; Jobbbox n'en reçoit et n'en garde rien.

Si l'appareil n'a ni Face ID, ni empreinte, ni code, le verrouillage ne peut pas être activé : définissez-en un d'abord dans les réglages de l'appareil.
