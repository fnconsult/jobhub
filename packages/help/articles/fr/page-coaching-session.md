Après une séance, votre coach humain peut publier un compte rendu. Dans « Mes coachs humains », « Lire le compte rendu et poursuivre la conversation » ouvre la conversation propre à cette séance. Le message porte le nom du coach et « Coach humain » ; ce n’est pas une réponse du coach IA. Le coach IA peut ensuite vous aider à organiser les prochaines étapes : seules les actions qui ne recopient aucun texte sont proposées. Une correction du compte rendu est un nouveau message. Votre export de données inclut les comptes rendus, y compris les brouillons privés qui ne s’affichent pas sur la page.
