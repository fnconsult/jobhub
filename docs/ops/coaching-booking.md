# Cal.com Teams (#881)

Use the Jobbbox Teams account and a Collective or Round Robin event with exactly one host per coach, never a personal event or a managed Template. Set `CAL_COM_TEAM_ID` in Paramètres, and `CAL_COM_API_KEY` / `CAL_COM_WEBHOOK_SECRET` as Provider Secrets. Create a **team** webhook to `/api/coaching/booking/webhook` for `BOOKING_CREATED`, `BOOKING_RESCHEDULED` and `BOOKING_CANCELLED`; its HMAC-SHA256 signature covers the raw body.

The coaching Back Office can create a hidden Collective event or retrieve/verify and attach an existing event ID and host ID. Duration must match the offer. Creation disables built-in attendee/host emails; **this does not disable custom team workflows**. Disable every reminder workflow in Cal.com too, then set `CAL_COM_REMINDERS_DISABLED=true`. Review each flagged cal.eu link with its coach. No calendar OAuth token is handled by Jobbbox.

A create request whose remote outcome is unknown is never retried blindly. Find the deterministic `jobbbox-<coach UUID>` event in Cal.com and attach its ID. The retained creation record prevents duplicate automatic creation. Configuration attachment shares the Administrator audit transaction. A later change does not rewrite existing paid-session booking contexts.

Activation requires current human-authored private contract and privacy coverage `cal-com`, with `cal-com` in the privacy policy’s outside-EU recipients. Observation of its published fingerprint must span at least 30 days. Missing publication evidence delays activation, including restored/previously stopped installations. `COACH_SPACE_V2_ENABLED`, both keys, a team ID and reminder confirmation are also required. #889/#890/#518 are human gates; this implementation supplies no wording or approval.

The signed session claim is used once, not matched by participant email. Subsequent UID chains survive claim expiry. Source is shown as “via Cal.com”, never an inferred person. Manual date changes on linked sessions are rejected by the database; use Cal.com. Session cancellation/Withdrawal or account deletion queues remote cancellation separately, so a Cal outage cannot block a refund. The minute Worker retries due rows independently; its adapter reads remote status before repeating cancellation. Failed rows use five-minute backoff and do not starve others. Check unresolved `coaching_cal_cancellation` rows through operational tooling; do not clear them to hide a failed cancellation.

Delivery facts, sent notices and resolved cancellations are purged after 30 days. Expired unclaimed contexts and anonymous erased-claim routing are purged after seven days; unresolved remote cancellations remain until reconciliation. Candidate exports include owned booking/delivery facts without nonces, tokens or raw webhook bodies. Retention remains proposed for human #890 review.

Tests preload `e2e/support/fake-cal.mjs` outside the standalone bundle. Only `JOBHUB_TARGET=e2e` plus that deliberate harness can supply synthetic recipient/publication evidence; production and staging ignore it. The API transport in tests redirects to a local fake server; no real Cal account or booking has been created. Primary API verification and its limitations are recorded in `docs/research/issue-881.md`.

The official `@calcom/embed-react` 1.5.3 package ships the Cal.com Commercial License (EE). It permits development/testing without a subscription; production requires agreement to Cal.com’s terms and a valid appropriate subscription for the number of hosts. A human must verify procurement, licence and whether the Teams agreement covers this marketplace use (including the coss.com assessment requested in ADR-0096) before production use. Installing the package, setting a flag or this draft delivery is no such approval.

Signed out-of-order successor/cancellation deliveries are acknowledged only after minimized routing/date facts are durably queued. The HTTP handler drains known causal chains after commit; the minute Worker also replays them after interruption. No raw participant metadata, token or free-form reason is retained in this inbox. Associated pending facts are exported and erased with their Candidate; unresolved facts have the delivery log’s 30-day horizon. Anonymous erased UID routing lasts seven days so late successors are cancelled rather than restoring a deleted session. Linked manual **duration** edits, as well as date edits, return the same guarded409.

Withdrawal and retirement also advance only the private UID chain when a late provider reschedule arrives: the binding enters cancellation-only `closing` state, without restoring or moving the personal session. This allows queued successors and later descendants to be cancelled even after the prior binding was already marked cancelled. Provider cancellation completion marks that routing record cancelled; provider updates never restore an unavailable personal session.
