La vérification en deux étapes protège votre compte si quelqu'un accède à votre messagerie : après chaque connexion par lien magique, Jobbbox vous demande aussi un code de votre application d'authentification. Il vous faut une application d'authentification sur votre téléphone, comme Google Authenticator, Microsoft Authenticator ou 1Password. Sans application, vous pouvez aussi l'activer avec une clé d'accès (Face ID, Touch ID, Windows Hello) : « Activer avec une clé d'accès », dans la même rubrique.

1. Dans Mon compte, ouvrez la rubrique « Sécurité », puis cliquez sur « Activer avec une application ».
2. Dans votre application d'authentification, ajoutez un compte en scannant le QR code. Si vous ne pouvez pas le scanner, saisissez la clé affichée sous le QR code.
3. Saisissez le code à 6 chiffres que montre l'application dans « Code affiché par l'application », puis cliquez sur « Confirmer ».
4. Vos 10 codes de secours s'affichent, une seule fois. Cliquez sur « Copier » ou sur « Télécharger », et gardez-les en lieu sûr, hors de votre téléphone.
5. Cliquez sur « J'ai gardé mes codes ». La rubrique indique « Activée depuis le … », et un e-mail vous le confirme.
6. À votre prochaine connexion par lien magique, saisissez le code de votre application dans « Code de l'application », puis cliquez sur « Vérifier ». Sans votre téléphone, cliquez sur « Utiliser un code de secours » et saisissez l'un de vos codes : chacun ne sert qu'une fois.

Après cinq codes erronés, il faut attendre quelques minutes avant de réessayer. Pour arrêter, cliquez sur « Désactiver » dans la rubrique « Sécurité » ; si votre dernière vérification date de plus de 10 minutes, un code vous est d'abord demandé.
