## fr
- Un CV adapté qui cite une référence, un modèle ou un code (« A350 », « S4/HANA ») n'est plus pris à tort pour écrit en partie dans une autre langue, ni redemandé au coach IA pour cela.

## en
- A Tailored CV that names a reference, a model or a code (« A350 », « S4/HANA ») is no longer wrongly taken as partly written in another language, nor asked of the AI Coach again for it.
