title: Vérification en deux étapes
synonyms: [vérification en deux étapes, double authentification, authentification à deux facteurs, 2fa, mfa, deuxième étape, application d'authentification, totp, sécurité]
---
La vérification en deux étapes ajoute une deuxième étape à la connexion par lien magique : un code à 6 chiffres de votre application d'authentification, ou l'un de vos codes de secours. Elle est désactivée tant que vous ne l'activez pas dans Mon compte, rubrique « Sécurité ».

Tant que la deuxième étape n'est pas faite, Jobbbox n'ouvre rien d'autre que la page qui demande le code : ni vos pages, ni l'extension, qui vous invite à terminer votre connexion sur Jobbbox. Une connexion avec un fournisseur, comme Google, ne demande pas de code. Le code est demandé à chaque connexion par lien magique, sur chaque appareil.
