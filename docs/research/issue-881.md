# Cal.com Teams integration details (#881)

Verified 2026-11-10 against first-party source tag `v6.0.13`, commit `8c8a5b4ae98c4116f6876f051531b350ed58bb87`. This is the public API implementation, not confirmation of the current hosted account's configuration. No live Cal.com credentials or team were used. The hosted documentation domain remains blocked by the session proxy (403); source was read from the official GitHub archive. #844's research and errata remain the product decision background.

- Booking cancellation is `POST /v2/bookings/:bookingUid/cancel`, JSON `{ cancellationReason }`, with `Authorization: Bearer …` and `cal-api-version: 2024-08-13`. The controller explicitly documents this version and path: [bookings controller](https://github.com/calcom/cal.com/blob/v6.0.13/apps/api/v2/src/ee/bookings/2024-08-13/controllers/bookings.controller.ts).
- Team event types support creation at `POST /v2/teams/:teamId/event-types` and authenticated retrieval at `GET /v2/teams/:teamId/event-types/:eventTypeId`, requiring team administration: [team controller](https://github.com/calcom/cal.com/blob/v6.0.13/apps/api/v2/src/modules/teams/event-types/controllers/teams-event-types.controller.ts).
- Team output includes `teamId`, `hosts`, `schedulingType` (`collective`, `roundRobin`, `managed`), `lengthInMinutes` and `bookingUrl`: [output model](https://github.com/calcom/cal.com/blob/v6.0.13/packages/platform/types/event-types/event-types_2024_06_14/outputs/event-type.output.ts). Jobbbox must reject managed templates and multiple hosts rather than assuming a public personal URL belongs to its team.
- Creation accepts `hosts`, `schedulingType`, `lengthInMinutes`, `slug`, `hidden` and `emailSettings`: [input model](https://github.com/calcom/cal.com/blob/v6.0.13/packages/platform/types/event-types/event-types_2024_06_14/inputs/create-event-type.input.ts).
- `disableEmailsToAttendees` and `disableEmailsToHosts` suppress built-in emails, including reminders, **but do not suppress custom email workflows**: [email settings](https://github.com/calcom/cal.com/blob/v6.0.13/packages/platform/types/event-types/event-types_2024_06_14/inputs/email-settings.input.ts). Operations must disable team custom reminder workflows too; the application must not imply these two flags prove that workflows are disabled.

Webhook HMAC over the raw body, team scope, embed metadata, and `rescheduleUid` linking to the previous UID were verified against official documentation in #844's errata. Reschedule/cancellation author attribution must remain “via Cal.com” unless an authenticated actor can be established, never inferred from attendee email.

Runtime activation remains subject to human privacy/B2B versions, outside-EU recipient coverage and the 30-day publication gate (#890/#888). API integration does not approve legal wording or authorize activating an account.
