title: Pourquoi la vérification en deux étapes m'est-elle demandée ?
synonyms: [vérification en deux étapes, double authentification, 2fa, mfa, obligatoire, code demandé, application d'authentification, codes de secours, configurer, lien magique, désactiver, téléphone perdu, réinitialiser]
---
Comme coach, vous lisez les profils et les candidatures des candidats qui vous ont donné l'accès. Pour protéger ces données, la vérification en deux étapes est obligatoire pour les coachs humains, comme pour l'équipe Jobbbox.

Après un lien magique, si votre compte n'a encore aucun facteur, Jobbbox vous demande de configurer une application d'authentification avant d'ouvrir votre espace coach. Scannez le QR code avec votre application (Google Authenticator, Microsoft Authenticator, 1Password…), saisissez le code qu'elle affiche dans « Code affiché par l'application », cliquez sur « Confirmer », puis gardez vos 10 codes de secours et cliquez sur « J'ai gardé mes codes ». Ensuite, chaque connexion par lien magique vous demande un code de votre application. Une connexion par un fournisseur, comme Google, ne le demande pas.

Vous ne pouvez pas la désactiver : la rubrique « Sécurité » de Mon compte n'a pas de bouton « Désactiver ». Si vous perdez votre téléphone et vos codes de secours, demandez à l'équipe Jobbbox de la réinitialiser : vous recevrez un e-mail, et vous la configurerez de nouveau à votre prochaine connexion.
