Comme coach, la vérification en deux étapes vous est demandée dans l'app Jobbbox comme sur le site, après chaque connexion par lien magique. Saisissez le code de votre application d'authentification dans « Code de l'application » et touchez « Vérifier », ou touchez « Utiliser un code de secours », ou « Utiliser une clé d'accès » si votre compte en a une.

Si votre compte n'a encore aucun facteur, l'app vous propose « Configurer la vérification ». La configuration s'ouvre dans une page de jobbbox.ai, dans l'app : scannez le QR code avec votre application, saisissez le code qu'elle affiche dans « Code affiché par l'application », touchez « Confirmer », puis gardez vos 10 codes de secours et touchez « J'ai gardé mes codes ». L'app revient alors d'elle-même et ouvre votre compte. « Fermer » vous ramène à l'écran de la deuxième étape si vous voulez la faire plus tard.

Les limites de tentatives et la réinitialisation par l'équipe Jobbbox sont celles du site. L'app ne garde ni vos codes ni votre clé d'accès.
