title: Que faire quand l'extension affiche « Jobbbox ne reconnaît pas cette installation de l'extension » ?
synonyms: [ne reconnaît pas, installation, capture refusée, capturer cette page, ne peut pas être capturée, extension, chrome web store, non empaquetée, zip]
---
Jobbbox n'accepte que les envois de son extension telle que publiée sur le Chrome Web Store. Une copie installée autrement, par exemple chargée depuis un dossier sur votre ordinateur, peut lire votre connexion mais pas envoyer d'offre : le panneau de l'extension l'indique par « Jobbbox ne reconnaît pas cette installation de l'extension : la page n'a pas été envoyée. »

La page que vous consultez n'est pas en cause. Retirez cette copie dans chrome://extensions, installez l'extension Jobbbox depuis le Chrome Web Store, puis cliquez de nouveau sur « Capturer cette page » ou sur « Analyser cette offre ».
