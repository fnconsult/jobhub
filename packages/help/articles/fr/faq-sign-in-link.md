Jobbbox n'a pas de mot de passe. Sur la page « Se connecter à Jobbbox », saisissez « Votre adresse e-mail » puis cliquez sur « Recevoir mon lien de connexion ». Vous recevez l'e-mail « Votre lien de connexion à Jobbbox » : son bouton « Me connecter à Jobbbox » vous connecte. Si vous n'avez pas encore de compte, il est créé à ce moment-là.

L'e-mail contient aussi un code à 6 chiffres, pour vous connecter sur un autre appareil que celui où vous le lisez : saisissez-le dans « Saisir le code reçu par e-mail », sur la page qui attend le lien ou dans l'app, puis validez avec « Me connecter avec ce code ».

Le lien et le code sont valables 15 minutes et ne fonctionnent qu'une seule fois : utiliser l'un rend l'autre inutilisable. Un lien expiré ou déjà utilisé affiche « Ce lien de connexion n'est plus valable. Demandez-en un nouveau ci-dessous. » Au bout de 5 codes faux, le code ne fonctionne plus : demandez un nouvel e-mail, qui apporte un nouveau code.

Selon les moyens proposés sur la page, « Continuer avec … » vous connecte aussi avec un autre compte que vous avez déjà, sans attendre d'e-mail.

L'e-mail n'arrive pas ?
- Attendez quelques minutes : il peut mettre un peu de temps.
- Regardez dans vos courriers indésirables (spam) ou vos promotions.
- Vérifiez l'adresse saisie, puis demandez un nouveau lien.

Toujours rien ? Voyez « Comment nous contacter ? ».
