## fr
- Connexion : « Recevoir un nouvel e-mail » s'affiche dès qu'un code est refusé, et reste affiché. Il disparaissait dès qu'un autre code était saisi, et n'apparaissait pas quand le lien avait déjà servi : il fallait recharger la page pour demander un nouvel e-mail.

## en
- Sign-in: « Send me a new email » appears as soon as a code is refused, and stays there. It used to disappear as soon as another code was typed, and did not appear when the link had already been used: you had to reload the page to ask for a new email.
